# GitHub Profile Explorer

Type a GitHub username, get their profile and repos, newest first.

My internship project at Hipo Labs, 2023. The rules: plain React and CSS, no UI libraries, no shortcuts. Dusted off in 2026 with a cleaner layout, mobile support and a few bug fixes. The hippo stayed.

## Run

```bash
git clone https://github.com/nihat3371/github-explorer-hipo
cd github-explorer-hipo
npm install
npm start
```

## Build

```bash
npm run build
```

## Stack

React 18, React Router 6, CSS modules

## Note

Uses the public GitHub API without a token, so it is rate limited to 60 requests per hour per IP.
