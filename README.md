# GitHub Profile Explorer

Search a GitHub username, see their profile card and repositories sorted by last update. Built for the Hipo Labs 2023 frontend challenge with plain React and CSS modules, no UI libraries per challenge rules.

## Run

```bash
git clone https://github.com/nihat3371/github-explorer-hipo
cd github-explorer-hipo
npm install
npm start
```

## Build

```bash
npm run build
```

## Stack

React 18, React Router 6, CSS modules

## Note

Uses the public GitHub API without a token, so it is rate limited to 60 requests per hour per IP.
